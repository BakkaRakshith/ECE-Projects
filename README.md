### `UNIT_001` — Automatic Night Lamp

**Objective:** Implement light-dependent switching.

An LDR-based circuit that switches an LED according to ambient light conditions.

- **Core concepts:** LDR, voltage divider, NPN transistor, current limiting
- **Platform:** Tinkercad Circuits
- **Status:** Simulation completed

[→ Access project](./automatic-night-lamp/)

### `UNIT_002` — Temperature-Controlled Fan

**Objective:** Automate fan switching using temperature feedback.

An Arduino-based system that monitors a TMP36 sensor and switches a simulated fan ON at 30°C or above, and OFF below the threshold.

- **Core concepts:** Analog input, sensor conversion, conditional logic, MOSFET switching
- **Platform:** Tinkercad Circuits
- **Status:** Simulation completed

[→ Access project](./temperature-controlled-fan/)

### `UNIT_003` — Traffic Light Controller

**Objective:** Execute a timed sequence of traffic signals.

An Arduino simulation controlling red, yellow, and green LEDs through a defined sequence.

- **Core concepts:** Digital outputs, timing, sequential control
- **Platform:** Tinkercad Circuits
- **Status:** Simulation completed

[→ Access project](./traffic-light-controller/)

## ⚙️ Development Protocol

Each project follows a repeatable process:

1. **Observe** — identify the objective and expected behavior.
2. **Analyze** — examine components, connections, and constraints.
3. **Implement** — construct the circuit or write the control logic.
4. **Verify** — test whether actual behavior matches expectations.
5. **Refine** — investigate errors and improve the implementation.
6. **Document** — record results, limitations, and lessons learned.

**A result is useful only when it can be explained and verified.**
